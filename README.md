# Финальное задание модуля 2: Поиск максимального значения в большом массиве данных

Решение финального задания по теме «Многопоточность» на Go.
Проект создан на основе шаблона
[Yandex-Practicum/go1fl-sprint9-final-tpl](https://github.com/Yandex-Practicum/go1fl-sprint9-final-tpl).

Программа генерирует большой слайс целых положительных чисел и находит в нём
максимум двумя способами: в одном потоке и в восьми горутинах. Время обоих
поисков измеряется в микросекундах.

## Реализация

- `generateRandomElements(size int) []int` — создаёт слайс заданного размера и
  заполняет его случайными положительными числами из диапазона
  `[1, 1_000_000]`. Для `size <= 0` возвращает `nil`.
- `maximum(data []int) int` — последовательно находит максимум. Для пустого
  слайса возвращает `0`, корректно работает с отрицательными числами,
  дубликатами и слайсом из одного элемента.
- `maxChunks(data []int) int` — параллельно находит максимум:
  - пустой слайс обрабатывается отдельно;
  - если элементов меньше `CHUNKS`, используется последовательный поиск;
  - иначе слайс делится на `CHUNKS` частей, и в каждой части максимум ищется
    в отдельной горутине;
  - последняя часть получает все оставшиеся элементы, поэтому ни один элемент
    не теряется, даже если длина слайса не кратна `CHUNKS`;
  - для ожидания горутин используется `sync.WaitGroup`;
  - результаты по частям сохраняются в отдельный слайс, после чего в нём
    находится итоговый максимум.

В `main` используются константы `SIZE = 100_000_000` и `CHUNKS = 8`.
Время измеряется через `time.Now()` и `time.Since(...).Microseconds()`.

## Запуск

```bash
go run .
```

## Проверка

```bash
gofmt -l .
go vet ./...
go test -v ./...
go test -race ./...
go test -cover ./...
```

Все unit-тесты проходят, в том числе под race detector. Тесты покрывают
пустой слайс, один элемент, отрицательные числа, длину меньше `CHUNKS`,
длину ровно `CHUNKS`, длину, не кратную `CHUNKS`, максимум в первом и последнем
чанке, а также сверяют результат `maxChunks` с результатом `maximum` на
различных размерах входных данных.

## Пример вывода

```text
Генерируем 100000000 целых чисел
Ищем максимальное значение в один поток
Максимальное значение элемента: 1000000
Время поиска: 73215 мкс
Ищем максимальное значение в 8 потоков
Максимальное значение элемента: 1000000
Время поиска: 9379 мкс
```

Конкретные значения времени зависят от запуска и загрузки компьютера, но оба
способа всегда возвращают одинаковый максимум.
